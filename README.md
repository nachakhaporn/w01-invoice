## 📝 เกี่ยวกับโปรเจค
โปรเจคนี้เป็นหน้าเว็บสำหรับสร้างและแสดงใบแจ้งหนี้แบบสวยงาม โดยใช้ HTML, CSS และ JavaScript เพื่อจัดการข้อมูลบริษัท ลูกค้า รายการสินค้า ภาษี และยอดรวมแบบง่ายและรวดเร็ว

## ✨ คุณสมบัติ
- แสดงข้อมูลบริษัทและลูกค้า
- ใส่รายการสินค้าและจำนวน
- คำนวณ subtotal, tax และ total อัตโนมัติ
- รูปแบบใบแจ้งหนี้ที่ดูเรียบร้อยและใช้งานง่าย
- เหมาะสำหรับใช้เป็น mockup หรือ template สำหรับการพัฒนาเว็บเพิ่มเติม

## 📁 โครงสร้างโปรเจค
```text
w01-invoice/
├── index.html
├── css/
│   └── style.css
├── js/
│   ├── data.js
│   └── index.js
├── img/
└── README.md
```

## ▶️ วิธีใช้งาน
1. เปิดไฟล์ `index.html` ในเบราว์เซอร์
2. ตรวจสอบข้อมูลในไฟล์ `js/data.js`
3. ปรับชื่อบริษัท ข้อมูลลูกค้า และรายการสินค้าให้ตรงกับงานของคุณ
4. ดูผลลัพธ์ใบแจ้งหนี้ที่แสดงบนหน้าเว็บ

โปรเจคนี้เป็นตัวอย่างใบแจ้งหนี้ที่สวยและใช้งานง่าย เหมาะสำหรับผู้เริ่มต้นที่ต้องการเรียนรู้การสร้างหน้าเว็บ static แบบจริงจัง โดยไม่ยุ่งยาก
